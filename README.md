# NEON TERRITORY · 네온 땅따먹기

모바일 웹용 3D 땅따먹기 게임입니다. 네온 격자 위에서 꼬리를 끌고 나가 내 영역으로 돌아오면 포위한 땅을 점령합니다. 적의 꼬리를 밟으면 격추하고, 내 꼬리가 밟히면 죽습니다. 혼자서는 스테이지 10개를 깨고, 멀티플레이에서는 최대 5명이 한 판에서 겨룹니다.

## 실행 방법

Node.js 18 이상이 필요합니다. 서버 하나가 정적 파일과 멀티플레이 WebSocket 을 함께 제공합니다.

```bash
cd game-ex2
npm install
npm start
```

브라우저에서 `http://localhost:8080` 을 엽니다. 휴대폰에서 실행하려면 같은 와이파이에서 PC의 IP 주소로 접속합니다. Three.js 는 CDN(jsdelivr)에서 불러오므로 인터넷 연결이 필요합니다.

싱글 플레이만 할 때는 `python3 -m http.server 8080` 같은 정적 서버로도 됩니다. 이 경우 멀티플레이 로비는 서버에 연결하지 못했다고 안내합니다.

## 조작

| 환경 | 조작 |
| --- | --- |
| 모바일 | 화면 아무 곳이나 누르고 끌면 그 방향으로 이동합니다. 손가락을 떼지 않고 방향을 바꿔도 됩니다. |
| PC | 방향키 또는 WASD. `P` 또는 `Esc` 로 일시정지. 멀티플레이에서는 메뉴만 열리고 경기는 계속됩니다. |

## 규칙

- 내 영역 밖으로 나가면 꼬리가 생기고, 다시 내 영역에 닿는 순간 꼬리와 포위된 칸을 모두 점령합니다.
- 적의 꼬리를 밟으면 적이 격추되고 적의 영역이 사라집니다. 내 꼬리가 밟히면 생명을 하나 잃습니다. 생명은 3개입니다.
- 영역이 전부 빼앗기면 그 개체는 제거됩니다.
- 싱글: 목표 점령률에 도달하면 스테이지 클리어, 시간이 다 되면 게임 오버입니다.

## 멀티플레이

타이틀 화면의 `멀티플레이` 버튼으로 들어갑니다.

1. 닉네임을 넣고 `방 만들기`를 누르면 4자리 방 코드가 나옵니다. `초대 링크 복사`로 `?room=코드` 링크를 나눌 수 있습니다.
2. 다른 사람은 코드를 넣고 `참가`를 누른 뒤 `준비 완료`를 누릅니다. 한 방에 최대 5명입니다.
3. 방장은 봇 수(0~3기)를 고르고, 모두 준비되면 `게임 시작`을 누릅니다. 참가자와 봇을 합쳐 2 이상이어야 합니다.

경기 규칙은 다음과 같습니다.

- 목숨은 각자 3개입니다. 사람은 죽어도 영역을 유지하고, 목숨을 모두 잃으면 탈락해 영역이 사라집니다.
- 누군가 점령률 35%에 먼저 닿으면 그 사람이 이깁니다. 150초가 지나면 점령률 순위로 결정합니다. 사람 참가자가 한 명만 남아도 끝납니다.
- 접속이 끊긴 사람의 개체는 봇 AI 가 이어서 조종하고, 90초 안에 같은 브라우저로 돌아오면 자기 자리로 복귀합니다.
- 서버가 게임 규칙을 돌리고, 클라이언트는 방향 입력만 보냅니다. 서버는 50ms 마다 바뀐 칸과 개체 위치를 방 전체에 보냅니다.

## 점수 (싱글)

| 항목 | 점수 |
| --- | --- |
| 점령 | 칸당 10점. 한 번에 30칸 이상이면 ×2, 80칸 이상 ×3, 150칸 이상 ×4. 빼앗은 칸은 5점 추가 |
| 격추 | 500점. 영역 전멸로 제거하면 800점 |
| 클리어 보너스 | 남은 시간 1초당 15점, 남은 생명 하나당 400점 |

별 등급: 죽지 않고 시간을 30% 이상 남기면 ★★★, 한 번 이하 죽으면 ★★, 그 외 ★.

## 스테이지

스테이지는 10개입니다. 뒤로 갈수록 격자가 넓어지고 적이 많아지며, 적이 더 빨라지고 더 자주 내 꼬리를 노립니다. 목표 점령률도 20%에서 45%까지 올라갑니다. 클리어하면 다음 스테이지가 열립니다. 스테이지별 최고 점수와 별, 종합 랭킹(상위 10명)은 브라우저 `localStorage` 에 저장됩니다.

## 설정

타이틀 화면 아래 버튼으로 효과음, 음악, 진동, 화질을 켜고 끌 수 있습니다. 진동은 `navigator.vibrate` 를 지원하는 브라우저(안드로이드 크롬 등)에서만 동작합니다. 화질 "자동"은 모바일이면 중간, PC면 고화질을 고릅니다.

## Render 배포

저장소에 `render.yaml` 이 있어 Blueprint 로 바로 올릴 수 있습니다.

1. [Render](https://render.com) 에 GitHub 계정으로 로그인합니다.
2. `New` → `Blueprint` 에서 이 저장소를 고르면 `render.yaml` 대로 무료 웹 서비스(싱가포르 리전)가 만들어집니다. 아래 버튼으로도 같은 화면이 열립니다.

   [![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/revfactory/neon-territory)

3. 배포가 끝나면 `https://<서비스 이름>.onrender.com` 으로 접속합니다. HTTPS 이므로 WebSocket 도 자동으로 `wss` 를 씁니다.

무료 인스턴스는 15분 동안 아무 트래픽이 없으면 잠들고, 다음 접속 때 깨어나는 데 1분쯤 걸립니다. 로비 화면이 "서버를 깨우는 중"을 표시하며 자동으로 다시 시도합니다. 경기 중에는 WebSocket 메시지가 계속 오가므로 잠들지 않습니다.

환경 변수 `NEON_MATCH_TIME` 으로 한 판 제한 시간(초)을 바꿀 수 있습니다. 기본값은 150입니다.

## 파일 구성

```
index.html        진입점 (Three.js importmap, 화면 마크업, 멀티 로비/결과 화면)
css/style.css     네온 UI 스타일
js/stages.js      스테이지 10개 정의
js/grid.js        영역 격자, 포위 점령(flood fill)
js/game.js        게임 규칙, 개체 이동/충돌, 점수, 스테이지 흐름, 멀티 승패 (서버와 공유)
js/ai.js          적 AI (서버와 공유)
js/render3d.js    Three.js 렌더러 (인스턴싱, 블룸, 파티클, 카메라)
js/ui.js          화면 전환, HUD, 점수판, 멀티 로비
js/net.js         WebSocket 연결/재접속, 서버 상태를 비추는 NetGame
js/audio.js       웹오디오 효과음/배경음 신스
js/haptics.js     진동, 화면 플래시
js/input.js       터치/키보드 입력
js/storage.js     localStorage 저장
js/app.js         앱 흐름
server/index.js   정적 파일 + WebSocket 방 관리 + 권위 시뮬레이션(20Hz)
render.yaml       Render Blueprint (무료 웹 서비스)
```
